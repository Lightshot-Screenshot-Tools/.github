## 🧠 Overview

**Lightshot** is a lightweight screenshot utility designed to make capturing and sharing selected areas of your desktop quick and convenient. Instead of saving an entire screen, users can immediately select a specific region and work with the captured image through a compact editing interface.

The application includes practical annotation tools for adding arrows, lines, highlights, text, and other visual elements before saving or sharing a screenshot. Its simple workflow makes it suitable for documenting software issues, creating tutorials, preparing visual references, or quickly communicating information from the screen.

Built for users who want a straightforward screenshot workflow without a complicated image-editing environment.
